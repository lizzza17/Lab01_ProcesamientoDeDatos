**Laboratorio de Python: principiante**

Este es un pequeño laboratorio con toda la base de python, divido en cuadernos con todo lo básico para empezar a programar :)

**Contenido:**

1.La base de las cadenas de texto y todo lo que se puede hacer con strings.
2.Sobre las tuplas (esas estructuras que no se dejan cambiar).
3.Acerca de las listas, donde se puede guardar de todo un poco y modificar.
4.Manejo de conjuntos para no repeticiones y operaciones rápidas, más ordenado.
5.Los diccionarios, estructuras clave-valor para organizar la información.
6.Sobre los condicionales, iguales que en muchos lenguajes, para tomar decisiones en el codigo.
7.Aprendiendo de bucles, para la repeticion de tareas (for y while).
8.Las funciones, organizando el código en bloques reutilizables y limpios.
9.Un repaso de programación Orientada a Objetos (clases, objetos en python).
10.Ejercicios prácticos, con nombres muy creativos.
